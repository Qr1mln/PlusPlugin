# PlusPlugin 项目架构图 7（核心执行链路 · 手绘风）

> 本图从**核心执行链路**视角重画（事件类型 → `plugin : script-engine` → `Dll` 注入载荷 → 宿主窗口），
> 采用 mermaid 手绘风（`look: handDrawn`），可直接在 GitHub / IDE 预览。基于当前源码事实，非计划。
>
> 对应源码：`editor/`、`plugin/script-engine/`、`proxy/`、`framework/`、`sdk/pplugin.h`。
> 全貌与逐包说明见 `架构图.md`；插件 UI 封装层决策见 `架构图6.md`。

## ① 主图：一条脚本事件从编辑到落点击的全链路

```mermaid
%%{init: {'look': 'handDrawn', 'theme': 'base', 'themeVariables': {'background': 'transparent', 'primaryColor': 'transparent', 'secondaryColor': 'transparent', 'tertiaryColor': 'transparent', 'mainBkg': 'transparent', 'clusterBkg': 'transparent', 'edgeLabelBackground': 'transparent', 'lineColor': '#ffffff', 'defaultLinkColor': '#ffffff', 'nodeBorder': '#ffffff', 'clusterBorder': '#ffffff', 'primaryTextColor': '#ffffff', 'secondaryTextColor': '#ffffff', 'tertiaryTextColor': '#ffffff', 'textColor': '#ffffff', 'titleColor': '#ffffff'}}}%%
graph TB
    subgraph OUT["进程外 · 编辑器侧（Python）"]
        EDIT["editor/ 脚本编辑器<br/>编辑事件 + 定时任务 + 试跑"]
        subgraph EVT["事件类型（脚本 JSON，5 类）"]
            E1["鼠标事件"]
            E2["延迟事件"]
            E3["找图事件"]
            E4["文本事件"]
            E5["键盘事件"]
        end
        SCHED["定时任务<br/>editor/schedule.py · timepicker.py"]
    end

    subgraph HOST["宿主进程 TTVoice.exe（Flutter / ANGLE）"]
        subgraph DLL["Dll · proxy 注入载荷（version.dll）"]
            D1["注入宿主进程<br/>代理 version.dll · 转发真身"]
            D2["获取目标进程权限<br/>target.ini 指定 exe · PayloadThread"]
            D3["获取后台执行权<br/>Host 能力表 · 加载/卸载插件"]
            D1 --> D2 --> D3
        end
        subgraph SE["plugin : script-engine"]
            S1["TCP 127.0.0.1:47800<br/>收 load / play / stop"]
            S3["执行脚本<br/>engine：命令队列 + 执行线程"]
            S2["后台消息模拟<br/>input_win32：PostMessage 合成鼠标/键盘"]
            S1 --> S3
            S3 --> S2
        end
        VIEW["FLUTTERVIEW 子窗口<br/>Flutter 输入真实目标"]
    end

    EDIT -->|TCP 推送脚本| S1
    SCHED -->|到点触发| S1
    EVT -.->|脚本由这些事件组成| S1
    D3 -->|Host API / 进程内执行权| SE
    S2 -->|后台投递 WM_*| VIEW
    SE -.->|依赖 Dll 的注入与权限| DLL
```

> 读法：编辑器把 5 类事件组成的脚本经 **TCP 47800** 推给进程内的 `script-engine`；插件把事件翻译成
> 鼠标/键盘消息，**直接投给宿主自己的 `FLUTTERVIEW` 窗口**（背景执行、不抢前台、不动真实键盘）。
> 这一切得以在目标进程内发生，靠的是 `Dll`（version.dll 代理载荷）先注入、拿到宿主进程权限与后台执行权。

## ② script-engine 插件内部模块

```mermaid
%%{init: {'look': 'handDrawn', 'theme': 'base', 'themeVariables': {'background': 'transparent', 'primaryColor': 'transparent', 'secondaryColor': 'transparent', 'tertiaryColor': 'transparent', 'mainBkg': 'transparent', 'clusterBkg': 'transparent', 'edgeLabelBackground': 'transparent', 'lineColor': '#ffffff', 'defaultLinkColor': '#ffffff', 'nodeBorder': '#ffffff', 'clusterBorder': '#ffffff', 'primaryTextColor': '#ffffff', 'secondaryTextColor': '#ffffff', 'tertiaryTextColor': '#ffffff', 'textColor': '#ffffff', 'titleColor': '#ffffff'}}}%%
graph LR
    SP["script_plugin.cpp<br/>入口 GetDesc / init / tick / shutdown"]
    TCP["tcp_server.cpp<br/>TCP 47800 + nlohmann/json 协议"]
    ENG["engine.cpp<br/>命令队列 + 执行线程 + 日志线程"]
    IN["input_win32.cpp<br/>PostMessage 合成鼠标/键盘 + 键名解析"]
    SD["schedule.cpp<br/>定时任务调度"]
    HOST["sdk/pplugin.h 的 Host<br/>log / 窗口 / 能力表"]

    SP --> TCP
    SP --> ENG
    SP --> SD
    TCP -->|Push 命令| ENG
    ENG --> IN
    SD -->|Push / RunScripts| ENG
    SP -->|Host::log 等| HOST
    ENG -.->|日志入队 → 转发| HOST
```

| 文件 | 职责 |
|---|---|
| `script_plugin.cpp` | 插件入口：`GetDesc` + init/tick/shutdown + 崩溃捕获（进程内自建线程属明确放行的例外） |
| `engine.cpp` | 命令队列、执行线程、日志队列/日志线程、事件执行 |
| `tcp_server.cpp` | TCP 服务（`127.0.0.1:47800`，单客户端）+ 协议解析（nlohmann/json） |
| `input_win32.cpp` | `PP_*` 输入原语：`PostMessage` 合成鼠标/键盘 + 组合键解析 |
| `schedule.cpp` | 定时任务：`ReloadSchedule / GetSchedule / RunScripts / Delay` 命令 |

## ③ Dll（proxy 注入载荷）内部模块

```mermaid
%%{init: {'look': 'handDrawn', 'theme': 'base', 'themeVariables': {'background': 'transparent', 'primaryColor': 'transparent', 'secondaryColor': 'transparent', 'tertiaryColor': 'transparent', 'mainBkg': 'transparent', 'clusterBkg': 'transparent', 'edgeLabelBackground': 'transparent', 'lineColor': '#ffffff', 'defaultLinkColor': '#ffffff', 'nodeBorder': '#ffffff', 'clusterBorder': '#ffffff', 'primaryTextColor': '#ffffff', 'secondaryTextColor': '#ffffff', 'tertiaryTextColor': '#ffffff', 'textColor': '#ffffff', 'titleColor': '#ffffff'}}}%%
graph TB
    DM["dllmain.cpp<br/>解析真身 · 转发 17 个 version 导出 · 起 PayloadThread"]
    BS["bootstrap.cpp<br/>WebView2 CDP 开关 · 等窗口 → 起框架"]
    CFG["config.cpp<br/>target.ini（目标 exe / debug）"]
    LOG["log.cpp<br/>proxy.log + 插件日志扇出"]
    FW["framework/*.inc<br/>Host 能力表 · 扫描/加载/卸载插件"]

    DM --> BS
    DM --> CFG
    DM --> LOG
    BS --> FW
    LOADER["plugins\\<name>\\*.dll + plugin.json"]

    FW -->|LoadLibraryEx + init| LOADER
    LOG -.->|fan-out| LOADER
```

> 关键约束：proxy **不渲染**（无 Present hook、无 D3D/DXGI、无 overlay 窗口）——插件自带窗口与 UI，
> 只通过 `Host` 能力表访问宿主（见 `架构图5.md` / `架构图6.md`）。
