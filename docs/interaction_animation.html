1. 载入引导与生命周期

LoadLibrary 同名代理劫持 → NotifyPlatform({cmd:init}) → NotifyGhost(publishLog) → shutdown → FreeLibrary

  1. LoadLibrary(W)host → ghost version.dll 同名代理劫持：宿主按名加载，落到我们的代理 DLL，DllMain 只做绑定 + CreateThread(PayloadThread)
  2. LoadLibrary + GetProcAddressghost → platform GetProcAddress(h, "NotifyPlatform") BootStrap 同目录加载 framework.dll，解析唯一导出 NotifyPlatform（proxy/protocol.cpp:138）
  3. initghost → platform {"cmd":"init","dispatch":"140712345678903","ctx":"140712345678904"} 建立边界：platform 记下 dispatch/ctx 指针并启动 worker / WS 线程
  4. publishLogplatform → ghost {"cmd":"publishLog","text":"..."} 握手后 platform 可反向借用 ghost 能力（当前日志改由公共 log 模块直写）
  5. shutdownghost → platform {"cmd":"shutdown"} 卸载前调用：platform 停止线程，确认无在途调用
  6. FreeLibraryghost 卸载 FreeLibrary(frameworkDll) 热重载闭环：重载后 platform 重新 init 拿新指针，天然重来

2. ghost → platform（NotifyPlatform）

唯一导出签名 int NotifyPlatform(const char* reqJson, char* respJson, int cap)

  1. initghost → platform {"cmd":"init","dispatch":"…","ctx":"…","ini":{"target":"TTVoice.exe","debug":false}} handshake：交换 dispatch 指针 + 可选 ini 配置（framework.cpp:317）
  2. shutdownghost → platform {"cmd":"shutdown"} 停止线程、清理（framework.cpp:327）
  3. 其它任意 cmdghost → platform {"cmd":"<anything>"} → {"ok":true,"echo":"<anything>"} 未知命令不崩溃、不拒绝加载，只回 echo（framework.cpp:331）
  4. 非法 JSONghost → platform → {"ok":false,"err":"invalid json","code":400} 解析失败统一 400（framework.cpp:313）

3. platform → ghost（NotifyGhost）

int NotifyGhost(const char* reqJson, char* respJson, int cap, void* ctx)

  1. mainWindow {"cmd":"mainWindow"} → {"ok":true,"hwnd":"12345"} Flutter 顶层窗口（proxy/protocol.cpp:65）
  2. viewWindow {"cmd":"viewWindow"} → {"ok":true,"hwnd":"12345"} FLUTTERVIEW 子窗口（输入目标），protocol.cpp:78
  3. scale {"cmd":"scale"} → {"ok":true,"scale":1.25} DPI 缩放，protocol.cpp:91
  4. publishLog {"cmd":"publishLog","text":"..."} → {"ok":true} 日志回传（协议 §7.2；当前由公共 log 模块直写）
  5. grabFrame {"cmd":"grabFrame","out":"1407…","cap":33177600} → 501 not implemented 大二进制旁路：控制流走 JSON，像素走 buffer/指针（protocol.cpp:102）
  6. onUiThread {"cmd":"onUiThread","cmd":"<子命令>"} → 501 not implemented 需要宿主线程时使用（protocol.cpp:127）

5. framework WebSocket 命令

浏览器/编辑器 → CivetWeb /ws → CommandHandler::handle（command_handler.cpp:55）

  1. mouse · move{"type":"mouse","action":"move","dx":10,"dy":-5} 默认 action；派发到 input_dispatcher（PostMessageW，不动物理鼠标）
  2. mouse · moveTo{"type":"mouse","action":"moveTo","x":960,"y":540,"space":"view"} space 默认 view（客户区坐标），需 x,y≥0
  3. mouse · click{"type":"mouse","action":"click","x":960,"y":540,"space":"view","button":"left"}
  4. mouse · down / up{"type":"mouse","action":"down","x":960,"y":540,"button":"left"}
  5. mouse · scroll{"type":"mouse","action":"scroll","delta":-120}
  6. key{"type":"key","vk":65} // 0 < vk ≤ 255 按键（虚拟键码）
  7. text{"type":"text","text":"hello"} 输入文本（非空）
  8. delay{"type":"delay","ms":500}
  9. geometry{"type":"geometry"} → {"success":true,"data":{...窗口几何...}} 读取 viewWindow 客户区几何（window_target.cpp）
  10. cursor · watch / unwatch{"type":"cursor","action":"watch"} → {"success":true,"data":{"watch":true}} 订阅/取消光标推送（~30Hz）
  11. cursor（无 action）{"type":"cursor"} → 一次性读数 {"success":true,"data":{...}}
  12. pick · start{"type":"pick","action":"start"} // 或省略 action 进入取点：WH_MOUSE_LL 左键拾取
  13. pick · cancel / stop{"type":"pick","action":"cancel"}
  14. 未知 type / action{"success":false,"code":"9999"} 统一 error 码 9999；成功 0000
